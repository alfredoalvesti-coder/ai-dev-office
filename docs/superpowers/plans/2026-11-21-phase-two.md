# Fase 2 — Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implementar gestão autenticada de projetos e tarefas com histórico e interface funcional.

**Architecture:** Backend Spring modular com contratos REST validados, migração Flyway e transações. Frontend Angular mantém credenciais em memória e atualiza a tela apenas após respostas HTTP confirmadas.

**Tech Stack:** Java 21, Spring Boot 3.5, Spring Data JPA, Flyway, PostgreSQL, MockMvc/H2/Testcontainers, Angular 21, Signals, RxJS, Material, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-21-phase-two-design.md`

## Global Constraints

- Não alterar a migração V1; criar V2.
- Não persistir nem versionar credenciais; autenticação HTTP Basic configurada pelo ambiente.
- Usar DTOs e Bean Validation na API e `@Version` nas entidades mutáveis.
- Manter as versões fixadas no POM e package-lock.

## Review Focus

- Credencial ausente ou incorreta: APIs de gestão retornam 401; teste MockMvc.
- Página, ordenação e limites: paginação estável e validação; teste de API.
- Dependência inexistente, em projeto diferente ou cíclica: rejeitar sem persistir; testes de serviço/API.
- Transição inválida e escrita concorrente: rejeitar com conflito; testes do serviço/API.
- Falha de rede, vazio e erro de validação: UI preserva estado confirmado e dá retorno acessível; testes Vitest.
